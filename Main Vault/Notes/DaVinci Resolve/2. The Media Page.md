
#### Introduction
**Project Manager**
- Lets you make and use projects
- You can export projects to share them as .drp files
- Local, network, and cloud project libraries
	- Local projects are stored on your disk
	- Network projects are stored on your network
	- Cloud projects are stored on the cloud

**Resolve Interface**
- Pages are selected from the bottom
- Each page is a completely different mode; it's like a different app
- You can close panels by clicking their title in the interface
- You can edit multiple concurrent timelines at once.



#### Media Page
**Function**
- For importing and organizing media

**Media Storage Panel**
- Navigate on your system to any media you'd like to bring into your system
- Hoverscrub over media to see a preview of it

**The Media Pool Panel**
- Stores everything that lives in the project
- You can right click to create bins to organize your media
- You can import media by dragging it
- You can alter the appearance of the files in the media pool
- You can sort by metadata for organization
- You can auto sync audio and video clips, but this isn't required

**Bins Panel**
- The bins panel lets you see the hierarchy of the files in your project
- If you want to import files *and* their bins, drag them into the bins panel
- Smart Bins can act as custom live filters to give you even better organization

**Metadata Panel**
- Once a piece of media is selected, it'll display its metadata
- You can select what groups of data you want to be displayed
