**Nodes**
- Fusion is all about nodes. It's a flowchart of little boxes that you run images through to create whatever you want to make
- It's a compositing tool. It's used for putting images over other images. 
- A node is a box in the fusion interface that does one job. You link all of these boxes together to do fancy stuff to your image. There are a couple inputs on each node where you can attach other nodes.
