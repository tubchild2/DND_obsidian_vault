Goal
	To generate a village with a name, traits, and history that's set in Arcohaem.

Process
A. Create a village
1. Statistics (money, population, happiness)
2. Founding date
3. Simulation of time

B. Put the village in the world
1. Position in Arcohaem
2. Village geography
3. History Log
4. Historical Events

B. Give the village identity
1. Name
2. Traits and Statistics
	- Wealth increases by population x happiness%
	- Population increases by happiness%
3. Random Events
	- Events have different proc chances
	- It should select one every few years instead of one per year
4. Logic
	- Features apply an amount of wealth, happiness, and population per year, and when applied.
